# MijnSerenity 7.6.0 uploaden

1. Pak de ZIP uit.
2. Open de GitHub-repository van MijnSerenity.
3. Kies branch `main`.
4. Upload alle losse bestanden uit de uitgepakte map.
5. Kies **Replace files** wanneer GitHub dit vraagt.
6. Gebruik commitbericht:

   `MijnSerenity 7.6.0 Captain Experience`

7. Wacht tot Netlify bij **Production** de status **Published** toont.
8. Open MijnSerenity opnieuw en gebruik bij Instellingen eventueel één keer **Ververs**.

Bestaande Supabase-gegevens, Home Assistant-koppeling en lokale instellingen blijven behouden.
