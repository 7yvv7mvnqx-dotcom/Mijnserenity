MIJNSERENITY 7.11.0 — GITHUB UPLOAD
===================================

1. Maak voor de zekerheid eerst een backup van de huidige GitHub repository.
2. Upload ALLE bestanden uit deze ZIP naar de hoofdmap van de MijnSerenity repository.
3. Kies bij GitHub voor vervangen/overschrijven van bestanden met dezelfde naam.
4. Verwijder geen Netlify/Supabase environment variables.
5. Wacht tot GitHub/Netlify de nieuwe versie heeft gepubliceerd.
6. Open MijnSerenity op de iPhone/iPad en vernieuw één keer volledig.
7. Als een oude PWA-cache zichtbaar blijft: gebruik in MijnSerenity de herstel/vernieuw-functie of sluit de PWA volledig en open opnieuw.
