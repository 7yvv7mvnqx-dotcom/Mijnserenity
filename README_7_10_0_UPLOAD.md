# MijnSerenity 7.10.0 upload

1. Upload **alle losse bestanden** uit deze map naar de hoofdmap van GitHub/Netlify.
2. Overschrijf de bestaande bestanden.
3. Wacht totdat de deployment gereed is.
4. Sluit MijnSerenity volledig af en open de app opnieuw.
5. Controleer onder **Meer → Instellingen** dat versie **7.10.0** wordt getoond.

De bestaande gegevens, Home Assistant-instellingen en logboeken blijven behouden.
