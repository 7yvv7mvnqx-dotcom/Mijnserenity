# MijnSerenity Cloud 7.2.1 — upload

1. Pak het ZIP-bestand uit.
2. Upload **alle bestanden tegelijk** naar de hoofdmap van de GitHub-repository.
3. Verwijder bij het uploaden geen bestaande foto- of databestanden buiten deze set.
4. Wacht tot Netlify de nieuwe commit volledig heeft gepubliceerd.
5. Open daarna `https://mijnserenity.nl/?versie=721` rechtstreeks in Safari.
6. Verschijnt nog een oude versie, tik op **App herstellen en vernieuwen**.
7. Voeg MijnSerenity daarna opnieuw toe aan het beginscherm wanneer dat nodig is.

Maak geen nieuw account wanneer de bestaande aanmelding tijdelijk niet werkt. Gebruik zo nodig eerst **Wachtwoord vergeten?**.
