# Upload MijnSerenity 7.3.4 Live

1. Pak de ZIP uit.
2. Upload alle losse bestanden naar GitHub-branch `main`.
3. Gebruik als commitbericht: `MijnSerenity 7.3.4 radar camera 5 seconden`.
4. Wacht tot Netlify `Production: main — Published` toont.
5. Sluit MijnSerenity volledig en open de app opnieuw.

De Home Assistant-koppeling en bestaande camera-instellingen blijven behouden.
