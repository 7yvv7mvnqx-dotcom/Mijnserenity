# MijnSerenity Cloud 6.3.0

MijnSerenity is het digitale dashboard en logboek voor de Serenity.

## Belangrijkste onderdelen
- Captain Cockpit Live Varen met snelheid, koers, toerental, roerstand, kaart en camera
- Motortoerental met groene, gele en rode veilige zones
- Roerstand direct onder de grafische schipper aan het roer
- Uitgebreid Financieel Command Center met pictogrammen, trends en slimme inzichten
- CSV-export van het actuele financiële filter
- Reisplanner, vaarroutes, logboek, POI’s en technisch dashboard
- Home Assistant-boordstatus en boot-/gebruikersbeheer

## Publiceren
