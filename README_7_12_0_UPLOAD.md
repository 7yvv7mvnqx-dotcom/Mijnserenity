MIJNSERENITY 7.12.0 — TECHNIEK CARTOONS
========================================

Upload alle bestanden uit deze ZIP naar de hoofdmap van je GitHub-repository.
Overschrijf bestaande bestanden wanneer GitHub daarom vraagt.

Nieuw in deze versie:
- Speelsere cartoonstijl met humoristische teksten.
- Op elke knop in Techniek een eigen cartoonstatusblok.
- Motor, huishoudaccu, startaccu, diesel, drinkwater, vuilwater, zonnepaneel en systemen krijgen allemaal een eigen illustratie.
- Drinkwater en vuilwater blijven dynamisch meeveranderen met het tankniveau.
- Serviceworker-cache vernieuwd zodat alle nieuwe illustraties direct geladen worden.
