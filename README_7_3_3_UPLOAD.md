# Upload MijnSerenity 7.3.3 Live

1. Upload alle losse bestanden uit deze ZIP naar de GitHub-branch `main`.
2. Gebruik als commitbericht: `MijnSerenity 7.3.3 Live Home Assistant en camera’s`.
3. Wacht tot Netlify de productie-deploy als **Published** toont.
4. Open mijnserenity.nl eerst rechtstreeks in Safari en kies zo nodig **App herstellen en vernieuwen**.
5. Koppel Home Assistant op ieder apparaat één keer opnieuw via Home Assistant → Instellen.

De development-branch blijft beschikbaar voor toekomstige tests.
