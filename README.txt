# Serenity Cloud Starter

Dit is de eerste online versie van het Serenity Logboek.

## Belangrijk
Een lokaal HTML-bestand opent op iPad vaak niet goed in Safari.
Daarom moet deze map online gezet worden, bijvoorbeeld via Netlify, GitHub Pages of later een echte database/webapp.

## Bestanden
- index.html: de app
- manifest.json: basis voor 'zet op beginscherm'

## Werking nu
- Logboek invoeren
- Vertrekhaven automatisch uit vorige aankomsthaven
- Motoruren overnemen
- Waterkaarten-info plakken
- JSON/CSV back-up exporteren

## Volgende stap
Online zetten en daarna koppelen aan een echte database voor delen met Desiree.
