MIJNSERENITY CLOUD 6.0 — RESPONSIVE UPDATE

Dit is een updatepakket voor de bestaande MijnSerenity-app.

Bestanden:
- mijnserenity-6-responsive.css
- mijnserenity-6-nav.js
- head-snippet.html

INSTALLATIE
1. Upload de CSS en JS naar dezelfde map als index.html.
2. Voeg in <head> toe:
   <link rel="stylesheet" href="mijnserenity-6-responsive.css?v=6.0">
3. Voeg vlak voor </body> toe:
   <script src="mijnserenity-6-nav.js?v=6.0"></script>
4. Controleer of de viewport-regel in <head> staat.
5. Publiceer opnieuw en ververs Safari volledig.

Dit pakket:
- centreert de app op iPad en MacBook;
- gebruikt vrijwel de volledige schermbreedte;
- maakt de layout responsive;
- vergroot de onderste navigatie;
- maakt de navigatie zijdelings scrollbaar;
- verbergt de navigatie na vier seconden;
- toont de navigatie opnieuw bij aanraken, scrollen of muisbeweging.

LET OP

veilig updatepakket en geen volledige vervanging van de bestaande app.
