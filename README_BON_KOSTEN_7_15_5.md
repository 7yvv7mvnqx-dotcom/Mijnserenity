# MijnSerenity 7.15.9 — Bonherkenning en verplichte categorie

- Geen standaard Havengeld meer.
- Categorie moet bewust worden geselecteerd.
- Opslaan zonder categorie is geblokkeerd.
- Bedragen worden alleen automatisch ingevuld bij een duidelijk totaal/te-betalen-signaal.
- Landnamen en betaalstatussen worden niet als leverancier gebruikt.
- Onzekere OCR-regels worden niet meer als artikelen gegokt.
