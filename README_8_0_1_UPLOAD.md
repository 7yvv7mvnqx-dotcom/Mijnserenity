# Upload MijnSerenity 8.0.1

Deze versie corrigeert de iPhone-header definitief:
- de knop **Meer** bovenaan is op iPhone verwijderd;
- tijd, alarm, instellingen en systeemstatus passen binnen één rij;
- vaste minimumbreedtes zijn verwijderd;
- de kop en het commandopaneel zijn compacter gemaakt.

Upload alle losse bestanden naar de hoofdmap van de GitHub-repository en overschrijf de bestaande bestanden. Controleer daarna onder Instellingen dat versie **8.0.1** actief is.
