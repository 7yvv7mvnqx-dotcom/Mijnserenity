# MijnSerenity 7.5.3

- Automatisch varen heeft nu één gedeelde Aan/Uit-stand per boot.
- iPhone en iPad tonen dezelfde stand via Supabase Realtime.
- Slechts één apparaat houdt de GPS-recorderclaim; andere apparaten kijken mee.
- Bestaande lokale Aan-stand wordt automatisch naar de gedeelde stand gemigreerd.
- Uitzetten op één apparaat schakelt de actieve recorder ook uit.
- Startknop in de kop en Start in de onderste navigatie hebben een vaste klikafhandeling.
- Navigatie bevat een gecontroleerde fallback wanneer de veegpagina niet direct reageert.
