# MijnSerenity 7.9.9 upload

Upload alle losse bestanden uit deze map naar de hoofdmap van GitHub of Netlify en overschrijf de bestaande bestanden.

Daarna:

1. Wacht tot de publicatie gereed is.
2. Sluit MijnSerenity volledig af.
3. Open de app opnieuw.
4. Controleer onder **Meer → Instellingen** dat versie **7.9.9** wordt getoond.

In deze versie start **Start varen** alleen de GPS-opname. Waterkaarten wordt niet meer automatisch geopend.
