# MijnSerenity 7.5.7 upload

Volledige flat GitHub-upload voor de stabiliteitsreparatie.

Belangrijk na deploy:

1. Open MijnSerenity.
2. Ga naar Instellingen.
3. Tik één keer op **App herstellen en vernieuwen**.
4. Test eerst een korte opname:
   - Live varen openen;
   - Start opname;
   - wacht tot minimaal één GPS-punt zichtbaar is;
   - Stop opname;
   - controleer of het logboek automatisch opent en de tocht bevat.
5. Test daarna de onderste knoppen en veeg horizontaal tussen enkele pagina's.
