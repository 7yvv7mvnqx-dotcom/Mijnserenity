# Release 7.3.0 DEV

- Eén knop om via de officiële Home Assistant-login te koppelen.
- Geen YAML, webhookcode, Netlify secret of handmatig Home Assistant-token nodig.
- Automatische apparaatdetectie via de Home Assistant WebSocket API.
- Selectie via vinkjes voor Hue, Sonos, Apple TV, Ring en scènes.
- Veilige OAuth state-controle en intrekbare refresh token.
- Automatische vernieuwing van kort geldige access tokens.
- Home Assistant direct openen en loskoppelen vanuit de wizard.
- Storage Safety en lokale Development Mode blijven behouden.
