# Release 7.9.0 — Serenity IVMS Dashboard

De startpagina is vervangen door een geïntegreerd vaartuigdashboard in de stijl van een professioneel vessel monitoring system.

Het dashboard toont onder andere brandstof, drinkwater, huishoudaccu, snelheid, koers, wind, walstroom, zonne-energie, temperaturen, bilge, technische waarschuwingen, GPS, tankniveaus en het actuele weer. Ontbrekende sensoren worden eerlijk als niet gekoppeld weergegeven.
