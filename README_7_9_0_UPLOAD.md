# MijnSerenity 7.9.0 upload

Deze map kan rechtstreeks naar GitHub worden geüpload.

Nieuw in 7.9.0:
- volledig nieuw Serenity IVMS-startdashboard;
- live waarden uit het technische dashboard, GPS, weer en Home Assistant;
- automatisch gebruik van de ingestelde foto van Serenity;
- duidelijke iPhone-, iPad- en desktopindeling;
- compactere startpagina zonder dubbele kaarten;
- Home Assistant-sensoren voor temperatuur, Victron, walstroom en zonne-energie worden automatisch herkend.

Na upload: open MijnSerenity en gebruik zo nodig **App herstellen en vernieuwen** op het inlogscherm om de oude PWA-cache te wissen.
